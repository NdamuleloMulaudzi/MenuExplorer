# Menu Explorer

A simple restaurant menu application built with ASP.NET Core MVC.

## Features

- Browse menu items
- Filter by category
- Search menu items
- View item details
- View featured items
- Star ratings and vegetarian indicators
- Responsive design
- Menu data stored in JSON

## Tech Stack

- C#
- ASP.NET Core MVC
- .NET 8
- Razor
- HTML/CSS
- JavaScript

## Running Locally

### Requirements

- .NET 8 SDK

### Run

```bash
dotnet restore
dotnet build
dotnet run
